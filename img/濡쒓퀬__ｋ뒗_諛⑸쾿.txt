# 로고 이미지 넣는 방법

이 img 폴더에 아래 파일명으로 이미지를 올리면 사이트에 자동으로 표시됩니다.
파일이 없으면 해당 자리는 깨진 이미지 없이 자동으로 숨겨지므로,
준비된 로고부터 하나씩 올려도 됩니다. (파일명은 정확히 일치해야 합니다)

## 1. 사이트 로고 (헤더 좌측 상단)

- 파일명: logo.png
- 권장: 정사각형에 가까운 비율, 200×200px 이상, 배경 투명(PNG)
- 이 파일이 없으면 기본 픽셀 새싹 마크가 대신 표시됩니다.

## 2. 함께하는 기관 로고 (푸터 상단 로고 띠)

- 파일명: partner-1.png  (예: 교육부)
- 파일명: partner-2.png  (예: 한국과학창의재단)
- 파일명: partner-3.png  (예: 한신대학교)
- 파일명: partner-4.png  (예: 협력기관 — 필요 없으면 안 올리면 됨)
- 권장: 가로형 로고, 높이 100px 이상, 배경 투명(PNG)
- 화면에는 높이 34px(모바일 26px)로 정렬되어 표시됩니다.
- 로고를 하나도 올리지 않으면 로고 띠 전체가 표시되지 않습니다.

## 3. 카카오톡/SNS 공유 미리보기 이미지

- 파일명: og-image.png
- 크기: 1200×630px (필수에 가깝게 권장)
- 사이트 링크를 카톡 등으로 공유할 때 표시되는 대표 이미지입니다.
- 사업단 로고 + "한신대학교 디지털새싹 사업단" 문구가 들어간 이미지를 권장합니다.

## 업로드 방법 (깃허브)

1. 저장소에서 img 폴더로 이동
2. Add file → Upload files → 이미지 드래그
3. Commit changes → 1~2분 후 사이트 반영 (Cmd+Shift+R로 새로고침)

## 참고

- 로고 교체 시 같은 파일명으로 다시 올리면 덮어써집니다.
  (반영이 안 보이면 브라우저 캐시 — 강력 새로고침 하세요)
- 기관 로고는 각 기관의 로고 사용 규정(색상 변형 금지 등)을 확인 후 사용하세요.
