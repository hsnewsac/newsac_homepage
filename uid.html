🛠 관리자로 등록하는 방법

  1. Firebase 콘솔에 접속해 newsac-20d73 프로젝트를 엽니다.
  2. 왼쪽 메뉴에서 Firestore Database → 데이터 탭으로 들어갑니다.
  3. 컬렉션 시작을 눌러 컬렉션 ID를 정확히 admins 로 만듭니다. (이미 있으면 이 단계는 건너뛰고 문서 추가를 누르세요)
  4. 문서 ID 칸에 위에서 복사한 UID를 붙여넣습니다. ⚠️ 이메일이 아니라 UID 여야 합니다. 자동 ID 버튼을 누르면 안 됩니다.
  5. 필드는 아무거나 하나 넣으면 됩니다. 예: 필드명 role, 타입 string, 값 admin — 내용은 검사하지 않고 문서의 존재 여부만 봅니다.
  6. 저장한 뒤 이 페이지에서 [🔄 다시 확인] 을 누릅니다.

※ 여러 명을 관리자로 두려면 각자의 UID로 문서를 하나씩 추가하면 됩니다.
※ 보안상 admins 컬렉션은 콘솔에서만 편집할 수 있고, 웹에서는 등록·수정이 불가능합니다.

❓ 그래도 안 될 때

1. 문서 ID에 공백이 섞였는지 확인 — 복사 과정에서 앞뒤 공백이 붙는 경우가 많습니다.
2. 컬렉션 이름 확인 — admin 이 아니라 admins (복수형) 입니다.
3. 보안 규칙 게시 여부 확인 — firestore_보안규칙_v5.txt 가 게시되어 있어야 합니다. 위 진단에 권한 오류가 뜬다면 규칙 문제입니다.
4. 로그아웃 후 재로그인 — 인증 토큰이 갱신되며 해결되는 경우가 있습니다.
5. 강력 새로고침 — Ctrl+Shift+R (Mac은 Cmd+Shift+R)
